06 · payment gate
Payment is a human-approved transition.
The agent never touches the payment credentials. It only prepares the intent for a person to authorize.
Buyer View
1 The Human Gate
✓
Explicit Approval
User must click "Approve Payment" after reviewing the final amount and policy pass.
✓
Visual Confirmation
The UI clearly shows the breakdown of the selected item and any bounded upsells.
✓
No Auto-Pay
The system is hard-coded to wait for a manual interaction before order creation.
Server View
2 Secure Order Creation
✓
Razorpay Test Mode
Orders are created server-side using the Razorpay Node SDK.
✓
Secret Protection
API keys and Webhook secrets never leave the server environment.
