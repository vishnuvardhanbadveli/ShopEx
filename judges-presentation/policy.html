04 · deterministic policy
Verification is not a conversation.
ShopEx uses a separate, deterministic engine to verify candidates. The LLM extracts the intent, but the code enforces the boundary.
Verification Logic
  • Budget CapPrice + Upsell ≤ Intent Limit
  • Category MatchStrict SKU category validation
  • Stock AvailabilityReal-time inventory check
  • Delivery SLAETA ≤ Requested timeframe
  • Attribute FilterRequired features (e.g. "wireless")
