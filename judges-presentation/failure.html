10 · graceful failure
Failure is a first-class state.
ShopEx never silently retries or ignores errors. Every failure is captured in the audit trail and surfaced to the user for next steps.
Policy Rejection
The agent picks an item that breaches budget or delivery constraints.
Audit LogACTION: POLICY_CHECK
RESULT: REJECTED
REASON: BUDGET_EXCEEDED
Payment Decline
The payment provider declines the transaction (e.g. Test Mode simulation).
Audit LogACTION: PAYMENT_CREATE
RESULT: FAILED
REASON: PROVIDER_DECLINE
Signature Mismatch
The cryptographic HMAC signature does not match the expected value.
Audit LogACTION: VERIFY_SIGNATURE
RESULT: INVALID
REASON: HMAC_MISMATCH
Persistence Error
The transaction is verified but the evidence cannot be stored.
Audit LogACTION: STORE_EVIDENCE
RESULT: PAUSED
REASON: DB_UNAVAILABLE
